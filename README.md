# Bubble-Clean

Embark on an epic battle against disgusting germs in an infected bathroom! Your mission: eliminate these pests with powerful bubble weapons while earning points and upgrading your arsenal. Survive as long as possible, clean up the chaos, and become the Bubble Clean Hero.
